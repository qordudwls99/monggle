거의 다 됐어요! 데이터를 함께 보려면 무료 Supabase 연결이 필요해요.

  1. supabase.com 에서 무료 프로젝트를 만들어요.
  2. 좌측 SQL Editor 에 저장소의 supabase-setup.sql 전체를 붙여넣고 Run.
  3. Project Settings → API 에서 Project URL 과 anon public 키를 복사.
  4. 이 파일 index.html 상단의 CONFIG 두 값에 붙여넣고 저장.
📄 자세한 안내는 저장소의 SHIFT_SETUP.md 를 참고하세요.
